# DJI Osmo Pocket 4 — ინტერაქტიული 3D

DJI Osmo Pocket 4-ის ინტერაქტიული 3D ვიზუალი ბრაუზერისთვის. აგებულია [Three.js](https://threejs.org/)-ით (r169), ერთ HTML ფაილში. გარე 3D მოდელი ან ტექსტურა არ გამოიყენება — მთელი გეომეტრია და მასალები კოდითაა შექმნილი.

**საიტი:** https://dji-osmo-pocket-4-3d.vercel.app

## გაშვება

- **ლოკალურად:** საქაღალდეში გაუშვით `npx serve .` ან `python -m http.server` და გახსენით მითითებული მისამართი.

საჭიროა ინტერნეტი — Three.js და შრიფტი CDN-დან იტვირთება. საჭიროა WebGL 2-ის მხარდაჭერა.
