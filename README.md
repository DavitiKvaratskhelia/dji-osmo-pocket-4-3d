# DJI Osmo Pocket 4 — ინტერაქტიული 3D

DJI Osmo Pocket 4-ის ინტერაქტიული 3D ვიზუალი ბრაუზერისთვის. აგებულია [Three.js](https://threejs.org/)-ით (r169), ერთ HTML ფაილში. გარე 3D მოდელი ან ტექსტურა არ გამოიყენება — მთელი გეომეტრია და მასალები კოდითაა შექმნილი.

**საიტი:** https://dji-osmo-pocket-4-3d.vercel.app

## გაშვება

- **ლოკალურად:** საქაღალდეში გაუშვით `npx serve .` ან `python -m http.server` და გახსენით მითითებული მისამართი.

საჭიროა ინტერნეტი — Three.js და შრიფტი CDN-დან იტვირთება. საჭიროა WebGL 2-ის მხარდაჭერა.

## შენიშვნები

- მთავარი რეფერენსი: DJI-ის ოფიციალური ფოტოები (წინიდან, უკნიდან, 3/4). სიმაღლე 144.2 მმ გამოქვეყნებული სპეციფიკაციიდანაა; სხვა ზომები ამ ფოტოებიდან გაზომილი შეფასებაა (წინა ფოტო 0.2685 მმ/პიქს., უკანა 0.2495 მმ/პიქს.): სახელური ≈ 33.0 × 22 მმ (სისქე — 3/4 ფოტოებიდან), კამერის თავი ≈ 36 × 25.6 მმ, ეკრანის მოდული ≈ 30.6 × 49 მმ.
- გიმბალი აგებულია ცალკე ჯგუფებად, ღერძებზე მოთავსებული pivot-ებით: `gimbal_base` (pan) → `gimbal_roll` → `gimbal_tilt`; ეკრანი — `screen_mount`.
- ეკრანზე კამერის პრევიუ (პროცედურული მთა-ტბის კადრი) და რეფერენსში ჩანს მხოლოდ ის ინტერფეისის ელემენტები; ეკრანი ვერტიკალურ მდგომარეობაშია.
- ზუსტად არ ჩანს / მიახლოებითია: კორპუსის სისქე, კამერის თავის სიღრმე, იოკის უკანა ნაწილის ფორმა, გვერდითი ხვრელების ზუსტი ადგილი; ეს არ არის სერტიფიცირებული ზუსტი ციფრული ასლი.
- DJI-ის ლოგო ოფიციალური ვექტორია (Wikimedia Commons, „DJI Innovations logo.svg“), გეომეტრია უცვლელია.
- DJI და Osmo SZ DJI Technology Co., Ltd.-ის სავაჭრო ნიშნებია; ეს პროექტი არაოფიციალური, სადემონსტრაციო ვიზუალიზაციაა.
